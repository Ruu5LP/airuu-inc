# ギャルスクリプト（GyaruScript）

## 目的

「ちょっと面白いことがしたい」から生まれた、ギャル語の語彙をキーワードにした
おもちゃのプログラミング言語。実用性より「作って動かして笑う」が目的の遊びプロジェクト。
とはいえ変数・条件分岐・ループ・関数・再帰まで動く、ちゃんとしたインタプリタになっている。

## 状態

v1完成・動作確認済み。

## 中身

- `interpreter.py` — 字句解析→構文解析→評価までを行う単一ファイルのインタプリタ（Python標準ライブラリのみ、依存なし）
- `examples/` — サンプルコード（`.gal` 拡張子）
  - `hello.gal` — 変数・文字列結合・出力
  - `fizzbuzz.gal` — 条件分岐・ループ
  - `functions.gal` — 関数定義・再帰
- `tests/test_interpreter.py` — 動作確認テスト（pytest不要、`python3 tests/test_interpreter.py` で実行）

## 動かし方

```bash
python3 interpreter.py examples/hello.gal
```

## 文法（キーワード対応表）

| ギャル語 | 意味 | 例 |
|---|---|---|
| `うちの X は VALUE な` | 変数宣言 | `うちのnameは"Ruu"な` |
| `X は VALUE な` | 再代入 | `iはi + 1な` |
| `あげぽよ(EXPR)な` | 出力（print） | `あげぽよ("まじ卍")な` |
| `ワンチャン (COND) { ... }` | if | |
| `それな { ... }` | else | ifの後に続ける |
| `ぐるぐる (COND) { ... }` | while | |
| `ガチ勢 NAME(引数...) { ... }` | 関数定義 | `ガチ勢 kaijo(n) { ... }` |
| `もどす EXPR な` | return | |
| `まじ` / `うそ` | true / false | |
| `かつ` / `もしくは` / `ちがう` | && / \|\| / ! | |

演算子（`+ - * / % == != < > <= >=`）はそのまま記号を使う。文字列は `"..."`。
すべての単文（変数宣言・代入・print・return・式文）は「〜な」で終わる。ブロックは `{ }`。

## 振り返りメモ

- Python標準ライブラリだけで字句解析〜評価まで書けるのを再確認。トークナイザで
  ASCII語と日本語語を別の文字クラスにしないと「うちのname」のようにスペース無しで
  隣接した語がひと続きのトークンに融合してしまう、というのがハマりどころだった。
- 文字列の `\n` 等エスケープ処理に `str.encode().decode("unicode_escape")` を使うと
  日本語がバイト単位で誤変換されて文字化けする（多バイト文字を素朴なunicode_escapeに
  通すのは事故る）。自前の簡易デコーダに置き換えて解決。他のプロジェクトで文字列
  エスケープを扱うときも要注意。
