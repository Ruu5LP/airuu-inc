# 英会話練習ログ

ChatGPTとの英会話セッションを、新しいものを上に追記していく。

## 書き方

- 日付 / テーマ / レベル を見出しにする
- 覚えたいフレーズ、間違えた点（corrections）、気づき（learning points）を残す
- 完璧な記録より、続けて積み上げることを優先する

## ログ

### 2026-07-29 朝の独り言と仕事に行く前の英会話（beginner）

**フレーズ**

- `How's your morning so far?` — 今のところ、朝はどんな感じ？
- `Mornings are not my thing.` — 朝は苦手です。
- `But I'm getting there.` — でも、だんだん調子が出てきています。
- `I'm still waking up.` — まだ目が覚めきっていません。
- `I don't feel like going to work.` — 仕事に行く気になれません。
- `I don't feel like it.` — 今はその気分じゃないです。
- `Alright, I'm heading to work now.` — よし、そろそろ仕事に行ってきます。

**間違えた点（corrections）**

- ✕ `As a morning so far?` → ○ `How's your morning so far?`
- ✕ `I'm so sleeping.` → ○ `I'm so sleepy.`（`sleeping`=寝ている状態、`sleepy`=眠い状態）
- ✕ `But I getting there.` → ○ `But I'm getting there.`（進行形にはbe動詞が必要）

**気づき**

- 長い文章ではなく、2〜4語の短い塊に分けて覚える
- 朝や通勤中に、今の状態を英語で独り言にする
- 単語を思い出せなくても、同じ短文を何度も繰り返す
- まず正確さより、短い表現を口から出すことを優先する
